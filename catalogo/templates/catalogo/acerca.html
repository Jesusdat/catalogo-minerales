Acerca

Sobre el proyecto

Gabinete Mineral empezó como una app de Streamlit y creció hasta convertirse en una aplicación web con Django: el servidor en Python genera cada página, los datos viven en una base de datos SQL y las fotos se guardan junto con sus créditos.

El catálogo se edita desde un panel de administración privado; solo la cuenta del propietario puede entrar, y cada alta, cambio o baja queda registrada en el historial.
